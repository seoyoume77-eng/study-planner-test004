# 📚 초·중·고 전 과목 성적 향상 스터디 플래너 (2022 개정 교육과정 반영)

초등학생, 중학생, 고등학생 각 학년의 **2022 개정 교육과정 전 과목** 편제와 공부 비중을 반영한 반응형 웹/앱 스터디 플래너입니다.

## ✨ 주요 파일 구성
- `index.html` : 상단 탭 클릭으로 **초등 · 중등 · 고등** 플래너를 즉시 전환할 수 있는 통합 메인 페이지
- `elementary.html` : 초등학생 전용 바른습관 & 단원평가 플래너
- `middle.html` : 중학생 전용 내신 A등급 & 수행평가 플래너
- `high.html` : 고등학생 전용 수능 1등급 & 고교학점제 플래너

## 🚀 핵심 기능
1. **2022 개정 교육과정 전 과목 공부 비중 가이드** (1순위 주요과목 / 2순위 내신 중요과목 / 3순위 기타·예체능·세특)
2. **반응형 레이아웃** (PC 2단 대시보드 & 모바일 1열 앱 뷰)
3. **자바스크립트 없이도 동작하는 CSS `:checked` 인터랙션** (할 일 취소선, 학년 탭 전환, 신호등 점검, 오답 태그)
4. **성적 향상 3대 부스터**
   - 🚦 메타인지 신호등 자기점검 (`🔴` / `🟡` / `🟢`)
   - 🛠️ 오답 원인 태그 & `1일 · 3일 · 7일` 회전 복습 스탬프
   - 🧠 백지복습(인출 연습) 노트 & 클릭형 정답 서랍 (`<details>`)
5. **학년별 맞춤 집중 타이머** (초등 15분 / 중등 25분 / 고등 50분)
